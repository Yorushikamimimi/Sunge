# Sunge｜孙宇晨（孙哥）× 邵艾伦四小时访谈启发的 AI 个人档案

受孙宇晨（孙哥）与邵艾伦四小时访谈启发，用自然对话建立个人档案、记录生活与目标，让 Agent 在换对话后从文件恢复近况。

Sunge 是受 **孙宇晨（孙哥 / Justin Sun）与邵艾伦（Alan Shao）约四小时二十二分钟访谈**《对话孙宇晨：年轻人如何抓住 AI 时代的机会？》启发的**非官方开源 AI 个人档案与生活记录框架**。访谈中将 AI 接入饮食、睡眠、训练与日常决策的尝试，带来了一个具体问题：怎样让个人助手基于持续保存的信息，帮助用户回看生活、观察变化，并在新对话中接续，而不是每次从头介绍自己？

第一版用 **Markdown + Obsidian 可读档案 + Agent 操作规范**落实这条思路。你可以像聊天一样讲述近况，由能够读写文件的 Codex 等 Agent 整理长期概况、当前状态和按月生活记录，再结合已有依据给出可选择的反馈。原视频和项目原创摘要见[访谈材料与许可证](#访谈材料与许可证)。受访者没有参与开发或为本项目背书；访谈是灵感，不是必须接受的人生答案。

先完成一条简单流程：**少量问题初始化 → 自然聊近况 → 保存真实信息 → 给有边界的反馈 → 新对话从文件恢复**。这版没有 App、云服务、自动采集或提醒，也没有健康改善、准确人格分析或全面管理能力的效果证据。

## 这个项目具体做什么

- **通过自然对话建立个人档案**：按用户实际提供的信息，记录阶段、价值观与性格自述、兴趣偏好、现实约束和近期目标。首次只问少量问题，不要求实名或填完整套表格。
- **整理生活记录**：按需保存睡眠、饮食、活动与身体感受、精力、情绪和压力，以及学习工作、项目、娱乐、社交与恢复体验；金钱和关系由用户主动选择启用。
- **把目标和实际结果分开**：区分计划、已经做过的事、本人感受、设备读数、计算结果和 Agent 分析。保留日期、来源、约数、未知项与更正依据，帮助回看变化。
- **让建议有个人背景和边界**：结合目标与时间、钱、精力限制提出可选择的建议；一次疲劳不被写成疾病，重复出现的现象也不直接被解释成因果。
- **支持跨对话续接**：用文件保存上下文。新会话从用户选定的入口恢复概况、当前状态和必要近期记录；实际跑通过的工具与验证边界见 [CURRENT_PROGRESS.md](CURRENT_PROGRESS.md)。
- **保留用户的数据控制权**：公开仓库放空白模板、虚构示例和通用规范，真实记录进入被 Git 忽略的本地目录。用户可以减少字段、关闭领域、纠正信息或停止记录。

它适合希望尝试 **AI 个人助手、生活记录、个人档案与 Agent 跨对话记忆** 的人，也适合从孙哥与邵艾伦这场四小时访谈来到这里、希望把其中的 AI 使用思路变成可回看的日常流程的人。不要求用户每天记录全部领域，也不把休息或漏记变成欠账。

## 开始使用

你需要一个能够读写本地文件的 Agent。初始化小工具使用 Python 3.10+ 标准库，无须安装依赖。

```sh
git clone https://github.com/Yorushikamimimi/Sunge.git
cd Sunge
python3 scripts/init_vault.py
```

工具先验证忽略规则，再创建 `local-vault/` 的四份入口文件；不会覆盖已有文件，也不会生成空白的每日记录。把 **`local-vault/` 单独作为 Obsidian Vault 打开**，或直接阅读 Markdown。样例在 [examples/fictional-vault](examples/fictional-vault/START_HERE.md)，全部是虚构数据，与真实档案分开。

在 Agent 中打开 Sunge 工作目录，使用这段启动指令：

```text
请按 Sunge 的 AGENTS.md 中“个人助手”分支开始。
本轮选定 local-vault/START_HERE.md 为我的私人档案入口，允许你在 local-vault/ 内记录我实际提供的信息。
若尚未建立入口，先运行 scripts/init_vault.py；若已有记录，先恢复，不要重新初始化。
按 assistant/PROTOCOL.md 整理自然表达，保留日期、来源、约数、未知和纠正依据。
首次只问少量必要问题，其余可跳过；金钱与关系领域默认关闭。不要读其他私人目录。
```

你可以说“昨晚十二点左右睡着，七点起，早上吃了面包，今天有点累”，不必先填表。Agent 若无法读写文件，应明确说尚未保存，并提供可复制的改动；不能把一段聊天回复称为已写入档案。

以后在**新对话**中仍打开这个工作目录，发送：

```text
继续使用 Sunge。私人档案入口是 local-vault/START_HERE.md。
先读入口、PROFILE.md、CURRENT.md，以及 CURRENT.md 明确链接的必要近期月记录。
简短说明你恢复了什么，再处理我本轮的请求。已知信息不要重问，不扫描其他私人资料。
```

### 不同 Agent 的入口

本版使用 Codex 项目场景：工作目录设为仓库根目录，并在启动指令中明确 `AGENTS.md`。实际入口发现与验收等级见 [CURRENT_PROGRESS.md](CURRENT_PROGRESS.md)。不能假设所有 Agent 都会自动加载同一文件。

若你的工具只支持聊天或附件，请明确附上 `AGENTS.md`、[assistant/PROTOCOL.md](assistant/PROTOCOL.md) 和自己选定的必要档案。自行判断愿意交给该服务哪些信息；模型不能访问本地文件时，保存要由你完成。语音可以使用工具提供的转写，但不确定的时间、专名和说话人须保留待确认；本版未验收语音输入。

## 档案只分三类

| 文件 | 用途 | 更新时机 |
| --- | --- | --- |
| `PROFILE.md` | 身份与阶段、价值观、性格自述、偏好、兴趣、长期约束与领域开关 | 本人提供或纠正时 |
| `CURRENT.md` | 当前目标、近况、证据状态、待确认信息及近期日志链接 | 有实际变化时 |
| `logs/YYYY-MM.md` | 同一个月的生活记录、观察、建议与纠正历史 | 实际提供信息时 |

`START_HERE.md` 和本地 `AGENTS.md` 是入口与访问边界，不是额外的生活报告。不按话题、日期或聊天窗口新建报告。没有记录的日期不生成条目，不计算完成率、不催补。

记录可以涉及睡眠、饮食、活动与身体、精力情绪压力、学习工作项目、娱乐社交恢复、生活环境。金钱、关系及其他敏感信息按本人意愿启用，尽量不收集第三方身份、账户和精确地址。睡眠的卧床时间与实际睡眠时长分开；照片不能凭空产生热量；提示后完成不能写成独立掌握。详细规则见 [Agent 规范](assistant/PROTOCOL.md)。

你随时可以关闭领域、减少字段、改正信息或停止使用。停止后不再主动追问。涉及删除文件或历史记录时，Agent 应先说明具体范围，按你的明确决定执行；停止使用不自动删除记录。

## 数据与公开内容

公开仓库只包含空白模板、明确标为虚构的示例、通用规范、原创摘要和工具。`local-vault/`、`materials/local/`、`.local-checks/` 在任何写入前即被忽略。真实档案与示例不能混用；不要强制加入忽略目录，不要通过整目录上传来分享项目。

**保存在本机不等于在本机处理。** 使用云端 Agent 时，交给模型的信息仍由该服务处理，受其隐私设置和条款约束。Git 忽略只防止普通跟踪操作，不能防止强制添加、手动上传、云同步或信息被模型读取；本版不宣传默认离线或绝对隐私。

维护或公开自己的改版前，运行：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_public.py
```

检查工具采用公开文件清单，拒绝私人目录被跟踪，检查常见泄露标记和相对链接；**不能替代人工隐私与权利审查**。如增加公开文件，先审查，再更新工具中的 `PUBLIC_FILES`。提交时只列出已审查的具体文件。
